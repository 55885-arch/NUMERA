## 1. รู้จักโครงงานของเรา

- **ชื่อกลุ่ม / สมาชิก:** `[...]`
- **ชื่อโครงงาน:** NUMERA อาณาจักรแห่งตัวเลข: แพลตฟอร์มเรียนคณิตศาสตร์ตามหลักสูตร สสวท. แบบ Classroom + เกม 2D
- **แนวคิดและปัญหา (สั้น ๆ):** นักเรียน ม.ต้น ขาดแรงจูงใจในการฝึกโจทย์ซ้ำ ครูติดตามผลรายหัวข้อได้ยาก
  และนักเรียนบางคนไม่มีอุปกรณ์ NUMERA เปลี่ยนโจทย์คณิตศาสตร์เป็นการร่ายเวทในเกม 2D
  ให้ครูมอบหมาย "ดันเจียน" ตามหน่วยการเรียน ดูรายงานรายหัวข้อ และพิมพ์ใบงานจากคลังโจทย์เดียวกันได้

## 2. เลือกเส้นทางสร้างประโยชน์

- [x] **A ทดลองใช้จริง**: นักเรียน ม.ต้น 1 ห้อง (20–35 คน) และครูคณิตศาสตร์ 1 ท่าน
- [x] **B ใช้แก้ปัญหาในโรงเรียน**: สื่อการเรียนรู้คณิตศาสตร์ + ระบบติดตามผลสำหรับครู
- [ ] C ส่งประกวด: `[อยู่ระหว่างค้นหา]` (ตรวจสอบเวที เช่น NSC / งานนวัตกรรมเทคโนโลยี และวันปิดรับสมัคร)
- [x] **D นำเสนอในงานวิชาการ**: `[งานเปิดบ้าน / นิทรรศการของโรงเรียน ถ้ามี]`
- [x] **E เผยแพร่ผลงาน**: เว็บไซต์ต้นแบบ, คลิปสาธิต, คู่มือครู, GitHub
- [ ] F ถ่ายทอดความรู้ / G ต่อยอดเป็นนวัตกรรม (หลังทดลองใช้)

- **แนวทางหลักที่เลือก:** A + B (ทดลองใช้จริงกับนักเรียนและครูในโรงเรียน)
- **เหตุผล:** เป็นสื่อการเรียนสำหรับ ม.ต้น จึงต้องพิสูจน์ด้วยการใช้จริงในห้องเรียน วัดผลก่อน–หลังได้ชัด
- **สิ่งที่ต้องทำก่อน:** ต้นแบบที่ใช้งานได้ (หัวข้อจำนวนเต็ม), ครูคณิตศาสตร์ตรวจโจทย์และเฉลย, ขออนุญาตครู/โรงเรียนทดลองใช้

## 8. สรุปข้อตกลงของกลุ่ม

**ภายในวันที่ 31 ม.ค. 2570 กลุ่มจะทำให้เกิดผลลัพธ์สำคัญ**
1. ต้นแบบ NUMERA ใช้งานได้จริงออนไลน์ (Classroom + เกม + ดันเจียน + ใบงาน) อย่างน้อย 1 หน่วย (จำนวนเต็ม)
2. ทดลองใช้กับนักเรียน ม.ต้น ≥ 20 คน พร้อมผลทดสอบก่อน–หลังและแบบสอบถาม
3. แฟ้มหลักฐานและรุ่นปรับปรุงตามข้อเสนอแนะ พร้อมทำ Impact Report

**สิ่งที่ต้องการความช่วยเหลือจากครู/โรงเรียน:** ครูคณิตศาสตร์ตรวจโจทย์และเฉลย, อนุญาตให้ทดลองใช้ 1 ห้อง,
อนุญาตการใช้ Gemini API (ถ้าใช้) กับนักเรียนอายุต่ำกว่า 18 ปี, ห้องคอมพิวเตอร์/แท็บเล็ตช่วงทดลอง

**ความเสี่ยง/อุปสรรค และแผนรับมือ:**
- พัฒนาไม่ทันก่อน ธ.ค. → ทำเฉพาะ P0 และหัวข้อเดียว, ฟีเจอร์เสริม (AI, อันดับ) ทำ ม.ค.
- อินเทอร์เน็ต/อุปกรณ์ไม่พร้อม → ใช้ Paper Mode ใบงานพิมพ์แทน
- โจทย์/เฉลยผิด → ครูตรวจก่อนเปิดใช้ทุกชุด
- ช่วงวันหยุดปลายปีทำให้ทดลองไม่ครบ → นัดวันทดลองกับครูล่วงหน้า
